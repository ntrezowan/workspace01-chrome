# Workspace01 Privacy Policy

Last updated: 2026-09-11

Workspace01 is a Chrome extension that organizes open tabs into named workspaces.

## Data handled

- Workspace names, their order, and which workspace is active.
- For each workspace, the URLs and page titles of its tabs, used only to re-open the workspace if its browser window no longer exists.

## Where it is stored

All data stays in the browser in `chrome.storage.local`. Nothing is sent to the developer or to any third party. The extension makes no network requests and loads no remote code.

## Data removal

Deleting a workspace removes its saved tab list. "Reset all workspaces" removes everything. Uninstalling the extension removes all stored data.
